# SafeCampus (CampusShield)

Campus emergency assistance web application.

## Modules
- Student Emergency Request form (Medical, Security, Hostel)
- Campus location and floor selector
- Security guard response dashboard with alert sound and status updates

## Running Locally

Frontend:
```bash
npm install
npm run dev
```

Backend:
```bash
cd backend
npm install
node server.js
```
